# TAIZHOU Apple-Inspired Editorial Visual System

## Corporate palette

- White: `#FFFFFF`
- Warm white: `#F6F3EF`
- Title black: `#1D1D1F`
- Body gray: `#424245`
- Secondary gray: `#86868B`
- Divider gray: `#E5E5E5`
- TAIZHOU dark red: `#7E2027`
- Deep red: `#5B171C`

Recommended distribution:

- White/warm white: 75–82%
- Black/gray: 12–18%
- Dark red: 3–6%

## Brand palettes

### WANMIAN

Warm white, oatmeal, skin tone, soft gray, deep coffee.

Visual keywords: comfort, natural light, everyday life, trust, real touch.

### GEERNA

White, stone gray, oatmeal, deep coffee, black, silver gray.

Visual keywords: material, silhouette, architecture, restraint, long-term wardrobe.

### UIUP

Cool white, silver gray, graphite, sand, ice blue, limited bright accents.

Visual keywords: body, movement, city, light functionality, content energy.

## Typography

Recommended Chinese: PingFang SC when available; Microsoft YaHei or Noto Sans CJK SC as compatible alternatives.

Recommended English and numbers: Helvetica Neue or Arial.

Suggested sizes for A4:

- Cover title: 38–46 pt
- Chapter number: 72–96 pt
- Chapter title: 30–38 pt
- Thesis headline: 30–42 pt
- Page title: 23–27 pt
- Secondary headline: 15–18 pt
- Body: 10.5–11.5 pt
- Diagram node title: 11–13 pt
- Diagram supporting text: 8.5–10 pt
- Footer: 7.5–8.5 pt

## Page archetypes

1. Thesis page: one large conclusion, minimal supporting text
2. Architecture page: conclusion headline + full-width diagram
3. Metric page: 3–5 large numbers + light detail table
4. Evidence page: one real image + one number + one conclusion
5. Brand emotion page: 70–100% image + brand name + one statement
6. Brand rules page: color, type, people, scene, light, composition
7. Application page: packaging, detail page, social content, retail touchpoint

## Diagram grammar

Use:

- Layered architecture
- Dual-engine comparison
- Matrix organization
- Timeline
- Swimlane
- Decision gate
- Funnel
- User journey
- Data feedback loop
- Large-number dashboard

Limit radial diagrams to 4–6 per long document.

Avoid:

- Repeated center-circle layouts
- Large rounded cards
- Heavy borders
- Gradients and drop shadows
- Small diagrams floating in empty pages
- More than one dominant conclusion per page

## Brand image separation

Do not reuse a hero model, hero scene, hero lighting setup, or hero application across brands.

WANMIAN should not look like GEERNA with warmer colors. UIUP should not look like a younger GEERNA. Each brand needs its own people, scene, movement, crop, color, material, and media behavior.
