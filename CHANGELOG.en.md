# Changelog

[简体中文](CHANGELOG.md) | [English](CHANGELOG.en.md)

This project follows [Semantic Versioning](https://semver.org/).

## [0.1.4] - 2026-08-13

Apple-style GitHub presentation release.

### Added

- Chinese and English hero artwork with stable contrast across GitHub themes and accessible title/description text.
- Bento capability overview, compact navigation, and progressively disclosed use cases on both GitHub home pages.
- Tests for README hero presence, system-font use, and release-version consistency.

### Changed

- Reorganized both READMEs into a positioning → result → capability → choice → start → examples reading path.
- Preserved the six-image case gallery while improving headings, captions, and action-link readability.
- Aligned the Codex Plugin, Python project, SkillHub package, and GitHub Release on `0.1.4`.

## [0.1.3] - 2026-08-13

Feature scope and multi-channel distribution release.

### Added

- Checked implemented-capabilities list in both READMEs.
- Detailed Chinese and English scope matrices separating implemented, conditional, and out-of-scope features.
- Reproducible standalone SkillHub package and build script.
- Chinese and English SkillHub publishing, dry-run, and version-synchronization guides.
- SkillHub official CLI dry-run and distribution-consistency tests.

### Changed

- Codex Plugin, Python project, SkillHub package, and GitHub Release now share version `0.1.3`.

## [0.1.2] - 2026-08-13

Chinese-English documentation release.

### Added

- English project home page, complete getting-started guide, and use-case/prompt cookbook.
- English TAIZHOU case guide and explanations for all six representative pages.
- Bilingual document delivery rules covering terminology, edition format, and independent visual QA.
- Reciprocal language navigation and documentation consistency tests.

### Changed

- Plugin metadata now explicitly supports Chinese, English, and bilingual document delivery.
- The getting-started guide now includes a two-edition Chinese-English delivery example.

## [0.1.1] - 2026-08-13

Tutorial and positioning release.

### Added

- Complete guide from installation and skill selection to first delivery.
- Three end-to-end walkthroughs, including localized Word revision and read-only PDF audit.
- Ten business use cases with copy-ready prompts.
- Six enlarged gallery images covering the TAIZHOU cover, contents, and four high-information chart pages.
- Skill positioning, routing, input contract, output contract, and capability boundaries.

### Changed

- README now states the audience, delivery scope, and exclusions near the top.
- Trigger descriptions and responsibilities are clearer across all three skills.
- Plugin metadata emphasizes local rendering, page-by-page visual QA, and no API-key requirement.

## [0.1.0] - 2026-08-13

Initial public release.

### Added

- `aos-publish-document` publishing orchestration skill.
- `aos-author-word` Word creation, revision, rendering, and acceptance skill.
- `aos-process-pdf` PDF inspection, processing, rendering, and acceptance skill.
- Reproducible 20-page TAIZHOU DOCX/PDF open-source case.
- Open-source licenses, security policy, contribution guide, CI, and pre-release scanner.
