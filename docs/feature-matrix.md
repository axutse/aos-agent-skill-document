# 功能范围清单

[简体中文](feature-matrix.md) | [English](feature-matrix.en.md)

状态说明：`✅ 已实现` 表示仓库已有工作流或脚本；`◐ 有条件` 表示依赖本地软件、输入质量或人工确认；`— 不包含` 表示当前版本不提供。

## 内容规划与出版

| 功能 | 状态 | 条件与说明 |
|---|:---:|---|
| 多文件资料读取与整理 | ✅ | 可处理项目中 Agent 能读取的文档、表格、图片和 Markdown 资料 |
| 事实、推断、模拟值和缺失项分类 | ✅ | 未验证经营数字默认标记为 `企划模拟值` |
| 章节结构、页面蓝图和页数预算 | ✅ | 长文档在正式制作前先规划 |
| 白皮书、报告、提案、手册和品牌规范 | ✅ | 使用 `$aos-publish-document` |
| 同一版式批量生成 | ✅ | 默认先生成并验收一个样本，再批量处理 |
| 中文或英文单语言文档 | ✅ | 按用户指定语言交付 |
| 两套独立中英文版本 | ✅ | 先建立术语表，两套文件分别渲染验收 |
| 同页中英左右对照 | ◐ | 适合短内容；长文档优先使用独立版本 |
| 业务事实真实性认证 | — | 必须由资料来源和人工负责人确认 |
| 法务、财务或版权最终审批 | — | Skill 只能检查和提示，不能替代专业签审 |

## Word / DOCX

| 功能 | 状态 | 条件与说明 |
|---|:---:|---|
| 从零创建可编辑 DOCX | ✅ | 使用语义标题、段落、列表和表格结构 |
| 局部修改已有 Word | ✅ | 默认保留源文件并输出新文件 |
| 保留样式、分节、页眉页脚和页码 | ✅ | 局部修改优先，不重建无关内容 |
| 自动目录、标题层级与编号 | ✅ | 依赖规范的 Word 样式结构 |
| 原生可编辑表格与图片排版 | ✅ | 明确表格宽度、图片比例与页面几何 |
| 高清图片设置 | ✅ | 提供确定性处理脚本 |
| 作者、公司和个人元数据检查 | ✅ | 可在公开发布前清理 |
| 评论和修订记录清理 | ✅ | 公开版默认不保留，除非用户要求 |
| DOCX 转换为 PDF | ✅ | 需要 LibreOffice |
| Word 全页渲染检查 | ◐ | 需要 LibreOffice；缺失时只能完成结构检查 |
| 实时控制桌面版 Word UI | — | 当前 Skill 操作文件，不自动点击 Word 界面 |
| 宏、VBA 和复杂嵌入对象开发 | — | 当前版本不提供专门工作流 |

## PDF

| 功能 | 状态 | 条件与说明 |
|---|:---:|---|
| 页数、页面尺寸和旋转检查 | ✅ | 提供 JSON 结构检查结果 |
| 加密、表单、链接和元数据检查 | ✅ | 支持公开发布前审计 |
| PDF 元数据清理 | ✅ | 保留用户要求的标题和作者信息 |
| PDF 全页渲染 | ◐ | 需要 Poppler / `pdftoppm` |
| 逐页视觉验收 | ✅ | 检查缺字、裁切、重叠、模糊和异常空白页 |
| 页面联系表 | ✅ | 只用于总览，不能替代逐页检查 |
| Word 转换后 PDF 的二次验收 | ✅ | DOCX 和 PDF 分别检查 |
| 扫描件 OCR | — | 当前未内置 OCR；需先接入 OCR 工具或服务 |
| PDF 电子签章或数字证书签名 | — | 当前版本不包含签名能力 |
| Acrobat 全功能交互编辑 | — | 不替代 Adobe Acrobat |

## 质量、安全与发布

| 功能 | 状态 | 条件与说明 |
|---|:---:|---|
| 全页渲染、修复、重新渲染闭环 | ✅ | 布局敏感修改后必须重新检查 |
| 元数据与常见密钥格式扫描 | ✅ | 仓库提供公开发布扫描脚本 |
| 私有信息和客户数据提醒 | ✅ | 仍需用户确认资料公开权限 |
| 本地 Python 文档处理 | ✅ | 插件自身不需要 API Key |
| 外部云端转换 | — | 默认不上传到第三方转换服务 |
| TAIZHOU 20 页开源示例 | ✅ | 包含 DOCX、PDF、联系表和生成器 |
| TAIZHOU 149 页完整案例 | ✅ | 通过 GitHub Release 附件提供 |
| Codex Plugin 安装 | ✅ | 从仓库 marketplace 安装 |
| SkillHub 单 Skill 发行包 | ✅ | 由仓库脚本从同一源代码生成，避免双份维护 |

## 最低依赖

| 任务 | 必需或建议依赖 |
|---|---|
| 结构化 DOCX/PDF 检查和脚本 | Python 3.10+ 及 `requirements.txt` |
| DOCX 转 PDF、Word 页面渲染 | LibreOffice |
| PDF 页面渲染 | Poppler |
| Codex Plugin 使用 | 支持 Plugin/Skill 的 Codex 环境 |
| SkillHub 安装与发布 | SkillHub CLI 和平台账号 |

若某项依赖不可用，Agent 应明确说明只完成了哪些检查，不得把结构检查描述为完整视觉验收。
