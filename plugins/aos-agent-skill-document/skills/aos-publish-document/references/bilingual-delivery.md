# Bilingual delivery

Use this reference when the user requests Chinese-English or other multilingual document editions.

## Select the edition format

Choose one delivery pattern before authoring:

1. **Separate files**: default for reports, white papers, manuals, and long documents. Produce one DOCX and PDF per language.
2. **Paired sections**: suitable for policies, agreements, or reference material that readers compare section by section.
3. **Side-by-side pages**: suitable only when content is short and the page width can support both languages without shrinking text below a readable size.

Use separate files when the user does not specify a pattern. Chinese and English wrap differently, so forcing identical pagination can damage readability.

## Build a terminology contract

Before translating:

- list company, brand, product, person, department, metric, and legal names;
- preserve registered names unless the source provides an approved translated name;
- define one translation for every repeated heading and technical term;
- keep units, periods, values, assumption labels, and source references aligned;
- label unresolved translations instead of silently choosing a new official name.

## Author and synchronize

1. Establish one verified source-of-truth outline.
2. Complete the source-language facts, tables, and captions before translation.
3. Keep section identifiers, figures, table identifiers, and captions traceable across editions.
4. Adapt sentence structure for readability instead of translating word for word.
5. Preserve the same meaning, evidence status, and planning-assumption policy.
6. Record intentional content differences in the delivery summary.

## Typography and layout

- Use fonts that contain all required glyphs and are legally available in the target environment.
- Set Chinese and Latin type sizes by visual balance, not by identical numeric values alone.
- Expect English headings and labels to require more horizontal space.
- Recalculate table widths, callouts, navigation, and page breaks for each edition.
- Never reduce body text to an unreadable size merely to force matching page counts.

## Bilingual acceptance gate

Verify every edition independently:

- reopen DOCX and PDF;
- confirm language completeness and absence of untranslated placeholders;
- compare names, numbers, units, dates, table values, captions, and assumption labels;
- render every page at readable zoom;
- inspect glyph coverage, line wrapping, clipping, overlaps, tables, navigation, and pagination;
- report page-count differences and any remaining terminology decisions.

Do not approve one edition only because the other edition passed visual QA.
