# Editorial Design System

## Design goals

Build documents that feel deliberate, calm, and publication-ready rather than like exported slide decks.

## Core rules

- Use one primary visual focus per page.
- Make key content large; do not shrink content merely to create whitespace.
- Use conclusion-first headlines.
- Use a restrained palette: neutral background, dark text, one enterprise accent, and brand-specific colors only in brand sections.
- Use a consistent grid and baseline system.
- Separate emotional brand pages from technical specification pages.
- Use full-width images selectively for visual pauses.
- Use dark pages sparingly to create rhythm.

## Recommended hierarchy

- Cover title: 38-48 pt
- Section number: 72-110 pt
- Section title: 30-38 pt
- Thesis title: 30-44 pt
- Content title: 22-28 pt
- Secondary heading: 14-18 pt
- Body: 10.5-11.5 pt
- Caption: 8-9 pt

## Three page archetypes

### A. Conclusion + structure

Use for strategy, organization, governance, and workflows.

### B. Big number + detail

Use for production capacity, annual product counts, targets, budgets, conversion, and quality metrics.

### C. Image + one statement

Use for brand openers, material proof, product proof, people, packaging, and spatial imagery.

## Diagram language

Prefer:

- Layered architecture
- Two-engine comparison
- Capability bands
- Decision trees
- Swimlanes
- Funnels
- Timelines
- Ecosystem rings
- User journeys

Limit repeated radial diagrams and card grids.
